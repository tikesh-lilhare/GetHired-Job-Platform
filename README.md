## GetHired – Job Platform

A microservices-based online job portal that connects job seekers with recruiters. The platform allows job seekers to explore job opportunities and apply for positions, while recruiters can manage job postings and applications.
Built using Java, Spring Boot, Spring Security, JWT Authentication, React, MySQL, and Microservices Architecture.

---
## 🚀 Project Overview
GetHired is a full-stack online job portal developed using a microservices architecture. The application is divided into independent services, making it modular, scalable, and easier to maintain.

The platform provides separate functionalities for job seekers and recruiters, including user authentication, job management, and job application processing.

## ✨ Key Features
## 👤 User Management
- User registration and login.
- Secure authentication using JWT.
- Role-based access control.
- Separate roles for Job Seekers and Recruiters.
- Secure password management using BCrypt.

## 💼 Job Management
- Recruiters can create and manage job postings.
- Job seekers can browse available opportunities.
- View job details and requirements.
- Manage job listings.

## 📄 Application Management
- Job seekers can apply for available positions.
- Manage submitted job applications.
- Recruiters can access applications for their job postings.
- Track application information.
  
## 🔐 Security
- JWT-based authentication.
- Spring Security integration.
- Role-based authorization.
- Secured REST APIs.

## ⚙️ Microservices Architecture
- Independent services for different business functionalities.
- Service discovery using Netflix Eureka.
- Centralized API routing using Spring Cloud Gateway.
- Inter-service communication using OpenFeign.
- Independent MySQL databases for services.
